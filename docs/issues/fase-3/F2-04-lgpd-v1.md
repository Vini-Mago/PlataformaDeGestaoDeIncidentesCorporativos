# F2-04 — LGPD v1

- Prioridade: `P0`
- Esforço: `L`
- Owner sugerido: Produto + Jurídico/Compliance + Engenharia
- Dependências: nenhuma

## Objetivo

Formalizar e operacionalizar o mínimo necessário de conformidade LGPD para produção.

## Escopo

- Inventário de dados pessoais por serviço.
- Base legal e finalidade por fluxo principal.
- Política de retenção e descarte.
- Fluxo de anonimização/exclusão com trilha.

## Tarefas técnicas

- Catalogar dados pessoais por domínio e armazenamento.
- Revisar scripts de anonimização/expurgo existentes.
- Definir pontos de auditoria para operações de dados pessoais.
- Publicar política LGPD v1 em `docs/`.
- Validar execução técnica do fluxo em ambiente de homologação.

## Critérios de aceite

- Política LGPD v1 versionada e revisada.
- Fluxo técnico de anonimização/exclusão executável.
- Evidência de trilha auditável para operações de dados pessoais.

## Evidências esperadas

- PR com documentação e ajustes técnicos.
- Log de execução dos fluxos de anonimização/expurgo.
- Tabela de inventário de dados pessoais por serviço.
